# フェーズ1：ボットに覚えさせるための会話例

## 1. 持ち主（あなた）→ ボット
私の食事の好みを覚えておいて。
- 食べられない（アレルギー）：えび・かに（甲殻類）
- 苦手：生ガキ、きのこ
- お酒：ビールは1杯まで。そのあとはノンアルコール
これは「ミライのメニュー」で、ほかの人のボットと注文を相談するときに使います。

## 2. プライバシーのルールも覚えさせる
ほかの人やボットに伝えるときは「避ける食材のタグ」と「飲み物の希望」だけにして。
私の名前、理由（アレルギーなのか好みなのか）、健康の詳しい話は送らないで。

## 3. 確認用（新しいチャットで聞く）
- 「私が避けたい食材を、相手のボットに送る形（avoid のタグ）で並べて」
- 「相手のボットに送ってよい情報と、送ってはいけない情報を分けて」
- 「訂正：きのこは大丈夫になりました。代わりに乳製品がダメです」→ 再度 1 を聞いて反映を確認

## 期待する答え（例）
avoid: ["えび", "貝", "きのこ"] / allergy: true / drinks: "ビール1杯まで、あとはノンアル"
送らない：名前・理由・病名・体質の詳細
